# App branding assets

This repository keeps the artwork used by the Android app and its guides:

- [A1 light mark](PNG/a1-mark-light-256.png): the footer image read by
  [the guide builder](../../build_tools/release/guides.py).
- [Transparent A1 mark](../../zmala_phone/app/src/main/res/drawable-nodpi/zmala_brand_mark.png):
  the in-app logo and portrait fallback.
- [A3 dark app mark](../../zmala_phone/app/src/main/res/drawable-nodpi/zmala_app_icon.png):
  the Android launcher foreground, with padding for launcher masks.

The [shared branding pack](https://github.com/toastfr35/Zmala/tree/main/docs/branding)
owns the masters, alternate exports, previews, dimensions and generation prompts.
It records artwork generated from the approved A1 and A3 drafts. The intended
palette is navy #172033, lavender #AA91F0 and mint #55BA91.
Use that pack when updating artwork; unused copies are not retained here.

Terminal boot artwork is documented in
[ZmalaTerminal](https://github.com/toastfr35/ZmalaTerminal/blob/main/docs/branding/boot-artwork.md).
